## Overview

The AI Playground is a platform for experimenting with different AI models and algorithms. The primary languages used in this project are HTML and Python, making it easy to create interactive web interfaces and powerful backend functionalities.

## Features

- **Interactive Web Interface**: Built using HTML, the user interface is intuitive and easy to navigate.
- **AI Models and Algorithms**: Implement various AI models and algorithms using Python.
- **Bug Fixes and Improvements**: Regular updates and maintenance to ensure the platform runs smoothly.

## Installation

To get started with the AI Playground, follow these steps:

1. Clone the repository:
    ```sh
    git clone https://github.com/Zhong-J/AI-playground.git
    ```
2. Navigate to the project directory:
    ```sh
    cd AI-playground
    ```
3. Install the required dependencies:
    ```sh
    pip install -r requirements.txt
    ```
